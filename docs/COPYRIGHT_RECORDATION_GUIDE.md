คู่มือนี้สรุปข้อมูลสำคัญและข้อความสำเร็จรูปสำหรับใช้กรอกในระบบ **[e-Services กรมทรัพย์สินทางปัญญา](https://copyright.ipthailand.go.th)**

## 1. ข้อมูลพื้นฐานในการยื่นคำขอ
* **ระบบยื่นคำขอ:** https://copyright.ipthailand.go.th (เข้าใช้งานด้วยแอป **ThaiD**)
* **ประเภทงานลิขสิทธิ์:** **วรรณกรรม**
* **ลักษณะงาน:** **โปรแกรมคอมพิวเตอร์ (Computer Program)**
* **ชื่อผลงาน (ภาษาไทย):** โครงสร้างรูปแบบไฟล์ข้อมูลและโปรแกรมประมวลผล PyGrassReal 3D Splat (PY3S)
* **ชื่อผลงาน (ภาษาอังกฤษ):** PyGrassReal 3D Splat Single-Container File Format & Codec (.py3s)
* **ปีที่สร้างสรรค์ผลงาน:** 2026 (พ.ศ. 2569)
* **สถานที่สร้างสรรค์:** ประเทศไทย

## 2. ข้อความสำหรับกรอก "ลักษณะผลงานโดยย่อ" (สามารถ Copy ไปวางได้เลย)

```text
ผลงานโปรแกรมคอมพิวเตอร์และโครงสร้างข้อมูล PyGrassReal 3D Splat (นามสกุล .py3s) เป็นนวัตกรรมรูปแบบไฟล์คอนเทนเนอร์เดี่ยว (Single-Container Format) สำหรับเทคโนโลยี 3D Gaussian Splatting เพื่อแก้ไขปัญหาไฟล์ 3DGS เดิมที่ไม่มีข้อมูลเชิงกายภาพ (Physics Collision) 

โครงสร้างไฟล์ประกอบด้วยส่วนหัวคงที่ขนาด 128 ไบต์ (Fixed Binary Header) กำกับด้วยค่า Magic String "PY3S" ทำหน้าที่จัดสรรตำแหน่งหน่วยความจำและเชื่อมโยง 4 องค์ประกอบสำคัญเข้าด้วยกันในไฟล์เดียว ได้แก่:
1. ข้อมูลการแสดงผลทางสายตาแบบ 3D Gaussian Splatting (.spz)
2. ข้อมูลรูปทรงเรขาคณิตสำหรับตรวจจับการชนทางฟิสิกส์ (Low-Poly Collision Mesh)
3. ข้อมูลเมทาดาทาการแปลงตำแหน่งและการจัดแนวทางฟิสิกส์แบบ 1 ต่อ 1 (Synchronized Alignment Transform Matrix)
4. ภาพพรีวิวขนาดเล็ก (Thumbnail)

ผลงานนี้ครอบคลุมข้อกำหนดโครงสร้างทางเทคนิค (Specification) และชุดซอร์สโค้ดต้นฉบับในการเข้ารหัสและถอดรหัส (Codec Implementation) ในภาษา C++, Python และ TypeScript ซึ่งรองรับการทำงานร่วมกับ Unreal Engine 5, เว็บบราวเซอร์ และระบบกราฟิกสามมิติต่างๆ
```

## 3. เอกสารและไฟล์ที่ต้องแนบในระบบ
1. **สำเนาบัตรประจำตัวประชาชน** ของผู้สร้างสรรค์/เจ้าของลิขสิทธิ์ (หรือหนังสือรับรองนิติบุคคลหากยื่นในนามบริษัท)
2. **ไฟล์ข้อกำหนดเชิงเทคนิค (Specification):** แปลงไฟล์ `SPECIFICATION.md` เป็น PDF
3. **ไฟล์ซอร์สโค้ดต้นฉบับ:** รวมซอร์สโค้ด `Py3sFormat.h`, `Py3sReader.cpp`, `Py3sWriter.cpp`, `py3s_codec.py` เป็นไฟล์ PDF (ประมาณ 20-30 หน้า พร้อมระบุข้อความหัวกระดาษลิขสิทธิ์)
4. **ลิงก์อ้างอิงสาธารณะ:** ระบุ URL ของ GitHub Repository (เช่น https://github.com/PyGrassReal/pygrassreal-py3s-format) เพื่อใช้เป็นหลักฐานแสดงการเผยแพร่ครั้งแรก (First Publication)
